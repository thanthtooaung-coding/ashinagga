Capabilities

Designed specifically for Pāli

Every feature has been considered to make typing Buddhist canonical texts and notes seamless.

ā

Dedicated Pāli Row

An instant-access top row with all 10 essential Pāli characters: ā, ī, ū, ṅ, ñ, ṭ, ḍ, ṇ, ḷ, ṃ. No switching keyboards or hunting through symbols.

⏱

Fast Long-Press

Press and hold standard Latin letters to quickly input their diacritical forms (hold a for ā, n for ṅ / ñ / ṇ, t for ṭ, d for ḍ).

မြ

Dual Script Support

Switch between Roman IAST and traditional Myanmar script with a single tap on the spacebar/arrow key. Features full virama consonant stacking (္).

⚡

Velthuis Transliteration

Prefer typing in plain ASCII? Enable Velthuis mode to type double letters and punctuation shortcuts (aa → ā, .t → ṭ, ~n → ñ, .m → ṃ).

🔒

Zero Data Collection

100% offline. The app does not declare or request network access (android.permission.INTERNET). No keystroke logging, no metrics, no telemetry.

🎨

Themes & Haptics

Comfortable viewing with Light, Dark, and System-matching themes, along with subtle customizable haptic vibration feedback for tactile typing.

Typing Mode

Velthuis Transliteration Guide

For rapid touch-typists who prefer standard QWERTY keys without lifting fingers.

The Velthuis system is an internationally recognized method developed by Frans Velthuis in 1991 for writing Sanskrit and Pāli using basic ASCII keyboard characters. In Pāli Keyboard, when Velthuis mode is toggled on in Settings, combinations transform automatically:

Vowels:
aa → ā
ii → ī
uu → ū
Retroflexes:
.t → ṭ
.d → ḍ
.n → ṇ
.l → ḷ
Nasals:
"n → ṅ
~n → ñ
.m → ṃ

Installation

How to enable on Android

Android requires input method editors to be manually authorized in Settings.

1

Install App

Install Pāli Keyboard from Google Play Store or build directly from the open-source repository.

2

Open Setup

Launch the Pāli Keyboard app on your Android phone to view the setup guide.

3

Enable Keyboard

Tap "Enable Pāli Keyboard" to open Android Settings and turn on the switch.

4

Select as Input

Tap "Select Pāli Keyboard", choose it from the dialog, and test typing in the Try It box!
